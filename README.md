# BLLOM

A static photography and film portfolio built with HTML, CSS, and JavaScript. The site uses the selected perspective mark with a BLLOM wordmark.

## Run locally

From this folder, run `python -m http.server 8765` and open `http://localhost:8765/`.

## Content

- `assets/` contains optimized WebP copies of all 21 JPEG photographs supplied in `Downloads/xavier's photos`. The original files remain in Downloads.
- Four featured photographs and 17 gallery photographs open in a keyboard-accessible viewer. Use the arrow keys to move between images and Escape to close it.
- No video files were supplied. The film link points to the photographer's Instagram Reels page.
- `logo.svg`, `mark.svg`, and `favicon.svg` are the BLLOM identity assets. Sendable exports are in `brand-kit/`.

The site has no build step or external runtime dependencies.
